Step 4: Sequential Playback (IMPORTANT)

You CANNOT just replace image instantly.

You must:

Load GIF

Wait 500ms

Then load next

Example logic:

function playWord(word) {
  let letters = word.toUpperCase().split("");
  let i = 0;

  function nextLetter() {
    if (i < letters.length) {
      document.getElementById("avatar").src =
        "/static/signs/" + letters[i] + ".gif";
      i++;
      setTimeout(nextLetter, 500);
    }
  }

  nextLetter();
}

Now if user says “network”
It will show N → E → T → W → O → R → K
